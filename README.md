# Garmin → Google Sheets

Синхронизация Garmin с Google Таблицей. Скрипт забирает тренировки и дневные метрики и записывает их на листы **Activities** и **Daily**.

Листы дашборда (`Дашборд`, `Даш_расчёт`, `Свод2026`, `ЛФК`, `Боль` и остальные) скрипт не открывает: там формулы.

## Что попадает в таблицу

**Activities** — все активности с 1 января 2026. Одна и та же тренировка не добавляется второй раз (сравнение по ID). Тренировки за последние 7 дней обновляются, если Garmin дописал пульс, каденс или набор высоты уже после первой записи.

**Daily** — шаги, сон, HRV, стресс, Body Battery, VO2 и остальные дневные поля. Сегодняшний день не пишется: он ещё не закрыт. Последние 3 закрытых дня перечитываются каждый запуск, потому что сон и HRV часто доезжают на следующий день.

Если Garmin на запрос ответил ошибкой, уже заполненная ячейка не затирается пустым значением.

Даты пишутся как настоящие даты (`дд.мм.гггг`), числа — как числа. Старые текстовые даты и значения вида `5,080` приводятся к нормальному виду, чтобы формулы дашборда их видели.

Часовой пояс: `Asia/Novosibirsk`.

## Таблица

Нужны два листа:

- `Activities`
- `Daily`

Заголовки скрипт создаёт сам, если их ещё нет. Если столбцы уже стоят в другом порядке, скрипт пишет по имени столбца и этот порядок не меняет.

Таблицу нужно расшарить на email сервис-аккаунта Google (роль **Редактор**). ID таблицы — кусок из ссылки:

```
https://docs.google.com/spreadsheets/d/SHEET_ID/edit
```

## GitHub Actions

Workflow `Garmin to Google Sheets Sync` запускается каждый день в **11:00** по Новосибирску (`04:00 UTC`) и вручную из вкладки Actions.

Секреты репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что положить |
|---|---|
| `GARMIN_EMAIL` | почта Garmin Connect |
| `GARMIN_PASSWORD` | пароль Garmin Connect |
| `GOOGLE_CREDENTIALS` | весь JSON ключа сервис-аккаунта |
| `SHEET_ID` | ID таблицы из URL |

Токены Garmin сохраняются между запусками. Повторный вход паролем нужен только если сессия протухла: на частый вход паролем Garmin отвечает 429.

## Локальный запуск

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python sync_garmin.py
```

Файл `.env` в корне (он в `.gitignore`):

```
GARMIN_EMAIL=you@mail.com
GARMIN_PASSWORD=your-password
SHEET_ID=id-из-ссылки-на-таблицу
GOOGLE_CREDENTIALS={"type": "service_account", "project_id": "..."}
```

`GOOGLE_CREDENTIALS` — одна строка, весь JSON ключа.

Проверка логики без Garmin и без таблицы:

```
python -m unittest test_sync.py
```

## Настройки

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `SYNC_START_DATE` | `2026-01-01` | с какой даты забирать пропуски |
| `SYNC_DAYS` | не задано | если задано вместо даты: сколько дней назад смотреть |
| `DAILY_REFRESH_DAYS` | `3` | сколько последних закрытых дней перечитывать |
| `ACTIVITY_REFRESH_DAYS` | `7` | сколько дней назад обновлять уже записанные тренировки |
| `SYNC_TIMEZONE` | `Asia/Novosibirsk` | «сегодня» и «вчера» |
| `GARMIN_TOKEN_DIR` | `~/.garth` | где хранить сессию Garmin |

## Google Cloud

1. Создать проект в [Google Cloud Console](https://console.cloud.google.com/).
2. Включить Google Sheets API и Google Drive API.
3. IAM → Service Accounts → создать аккаунт → Keys → JSON.
4. Поделиться таблицей с email этого аккаунта, роль Редактор.
